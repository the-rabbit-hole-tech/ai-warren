# Inject values; never reveal them into files

- When a value only needs to reach a program, use your password manager's inject-and-run tool, which injects it and masks the output. The org or personal plugin names that tool.
- Never write a revealed value to a file, a log or a command line.

See secrets:credential-rules for where credentials live.
