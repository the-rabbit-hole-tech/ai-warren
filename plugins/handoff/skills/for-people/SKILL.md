# Hand-offs, letters and emails for other people

## Hand-offs
- Hand-offs for other people (developers, staff, vendors) are plain prose in the owner's voice ("I rotated the relay login", "I need you to"): no tables of technical detail, no third person, no agent framing.
- Include only what they need to act, with exact values (host, port, username) in a short closing list or code block where they'd copy them.
- Passwords are never included; the owner hands those over directly.
- Pages written for the owner keep the normal style.

## Letters and emails
- Before drafting a letter or email to someone, ask the owner which grade level or voice to write it in, then draft.
- When the owner is away, the ask waits in the owner queue (the host file names it).
- GitHub text and hand-off pages are outside this rule.
