# Licence and credit

- **CNCF projects: original author credit.** In every CNCF-style project the owner writes from the start, credit the original author (the handle the org or personal plugin names) as the original author: a NOTICE line, an AUTHORS file listing them first, and a README Acknowledgements section. Never a real name or an employer. File headers stay "<Product> Authors" and LICENSE is unchanged.

## Lessons
- **MIT repos name the holder, never "The <repo> Authors".** The "<Product> Authors" headers, NOTICE and AUTHORS files belong only to the Apache/CNCF projects. An MIT repo says `Copyright (c) <year> <holder>` in LICENSE, README and the manifest, with no NOTICE or AUTHORS file.
