A long-running Python service (web API or worker), in the `src/` layout.

### Tree

```text
.
├── src/<package>/
│   ├── __init__.py
│   ├── main.py           entry point: load settings, build the app, run
│   ├── settings.py       typed settings from the environment
│   ├── api/              transport: routes, request and response models
│   │   └── <resource>.py
│   ├── services/         business logic, free of HTTP and database types
│   ├── store/            persistence and external clients
│   └── py.typed
├── migrations/           ordered database migrations
├── tests/
│   ├── conftest.py       app, client and database fixtures
│   ├── unit/
│   ├── integration/      tests against real dependencies
│   └── data/             fixture files
├── Dockerfile
├── .env.example          every setting, with safe local defaults
├── pyproject.toml
├── Taskfile.yml
└── README.md
```

### What goes where

- `main.py`: wiring and start-up only; it creates the app with a factory so tests build their own.
- `settings.py`: the only place that reads the environment; it validates at start-up.
- `api/`: routing, validation and error mapping. It calls a service and holds no business rules.
- `services/`: the rules, free of framework and database types.
- `store/`: queries and clients behind small interfaces the services use.
- `migrations/`: generated by the migration tool, then reviewed. Never edit one that has shipped.

### Naming

- The import package is the repo name in `snake_case`.
- Modules and functions `snake_case`; classes `PascalCase`; a route module is named for its
  resource (`users.py`).
- Environment variables: `UPPER_SNAKE_CASE`, all listed in `.env.example`, including `LOG_LEVEL`
  and `LOG_FORMAT`.

### Tests, fixtures and generated code

- Unit tests in `tests/unit/` mirror the package; integration tests in `tests/integration/` are
  marked `@pytest.mark.integration` and run against containers.
- Shared fixtures go in `tests/conftest.py`; fixture files in `tests/data/`.
- Generated clients and models go in `src/<package>/_generated/`, are committed and rebuilt by a
  Taskfile task; never edit them by hand.
