# warren-org-__OWNER_LOWER__

The __OWNER__ rules for the ai-warren base. The `skills/` folder holds one skill per step that
__OWNER__ does its own way, and `scaffold/scaffold.conf` holds the values `warren-new-repo` uses
for new repos of this owner. Install it at user level from the `__OWNER_LOWER__` marketplace; the
marketplace README explains the naming rule and how to write your own rules.
