# Plans, specs and review formats

## Plans and specs
- Always write the full document to disk; it is for the owner's reference.
- Do not ask the owner to review the file. Show a concise on-screen summary and ask for approval on that.
- File placement follows the repo's layout block (defined in your shared rules repo) once it has one.

## Pick the format by content, not size
- Questions with options, even many of them, stay as AskUserQuestion in chat, in batches of up to 4.
- Where the host runs a hand-off site, a served review page is for reviews that mix content: screens, mockups, pictures, diagrams, walk-throughs, long text or diffs. See `handoff:review-page`.
