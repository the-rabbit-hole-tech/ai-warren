# Brainstorming and design

- Brainstorming and design always go through the superpowers skills, for example `superpowers:brainstorming`. Load it first and follow it; this skill adds the owner's rules on top and never replaces it.
- The owner's rules that apply on top, each in its own skill:
  - Where the plan or spec goes and how it is shown: `design:plans`.
  - Reviewing a design, plan or code one section at a time: `design:section-review`.
  - A visual design session (brand, colour, tokens, shell, screens): `design:design-session`.
  - New UI of any kind: `design:new-ui`.
